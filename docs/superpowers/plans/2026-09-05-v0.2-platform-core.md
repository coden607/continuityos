# ContinuityOS v0.2 Platform Core Implementation Plan

**Goal:** Turn the v0.1 skeleton into a reusable local-first AI application runtime with adaptive routing, durable continuity, plugin/MCP contracts, voice/memory seams, guardrails, health recovery, secrets, and observability.

## Delivered in this tranche

- Capability registry for models/providers.
- Routing telemetry with task-specific historical success scoring.
- SQLite checkpoint store for Context Capsules.
- Plugin manifest and plugin registry.
- MCP server registry with transport/auth metadata.
- Provider-neutral model request/result contracts plus optional LiteLLM adapter.
- Provider-neutral memory contracts plus zero-dependency in-memory adapter.
- Provider-neutral speech-to-text contract plus whisper.cpp adapter.
- Guardrail mesh for composing deterministic/NeMo/domain policies.
- Health supervisor for degrade/quarantine/recover transitions.
- OpenTelemetry-compatible tracer seam with in-memory implementation.
- Local secret manager with 0600 `.env.local` storage and GitHub CLI sync seam.
- NextLaw607 reference Continuum Pack.
- API and CLI surfaces that report ContinuityOS capabilities.
- CI, security scan, scheduled health-check, Renovate and pre-commit configuration.

## Next implementation slices

1. Real LiteLLM proxy/provider discovery and benchmark harness.
2. Context compressor and capsule verification with model-to-model handoff.
3. DBOS durable workflow adapter with SQLite/Postgres modes.
4. SOPS+age vault and multi-target secret-sync adapters.
5. Mem0 and Graphiti/FalkorDB concrete adapters.
6. NeMo Guardrails concrete adapter and tool-call policy gateway.
7. Pipecat/WebRTC streaming voice pipeline and local Whisper model management.
8. MCP Streamable HTTP client with tool discovery and scoped authorization.
9. OpenTelemetry exporters + Langfuse/Sentry adapters.
10. `continuity new` project generator and pack installer.
